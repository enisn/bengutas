BENGÜ TAŞ (BENGUTAS)

An open-source dual-family typography system translating the 8th-century epigraphic chisel geometry of the Orkhon Valley stelae into an authentic, monumental digital typeface.

🗿

Etymology: Bengü + Taş

In Old Turkic (𐰋𐰭𐰇 𐱃𐱁), Bengü signifies eternal, everlasting, immortal, while Taş means stone or monument. It translates literally as "The Eternal Stone".

📜

The 8th-Century Stelae

Erected by the Göktürks (AD 720–735) for Bilge Khagan, Kül Tigin, and Tonyukuk. In the inscriptions, the rulers declared: « bengü taş toqıtdım » — "I had an eternal stone carved so that the memory would not perish."

⚔️

Open Digital Immortality

Recognizing mortal life is fleeting, ancient masters carved basalt to outlast empires. Bengutas brings that 1,300-year-old lapidary grammar into an open digital asset under the SIL OFL 1.1 license.

Bengutas Display

STRICTLY NON-CURVILINEAR CHISEL PLANES

Designed with non-curvilinear 45° and 60° stone chamfers (no compass curves). All rounded forms (O, C, D, G, U, B, P) are chiseled as faceted basalt rings. Lowercase input renders balanced petite small-caps.

Lapidary Grotesque Companion

Bengutas Sans

Authentic double-chisel terminals with pristine grotesque legibility

A warm, epigraphic companion font designed for extended reading. Replaces sterile 90° box endings with 25°–30° stone-chisel terminal cuts (c, e, s, r), lapidary stem heads (i, l, n, u), and authentic Orkhon broken chevron hooks (ç, ş)—anchored by strictly flat baselines for effortless text flow.

ARCHAEOLOGICAL SURVEY • VOL. VIII

ON THE CHISEL METRICS OF THE SECOND TURKIC KHAGANATE

The basalt monuments erected along the Orkhon river basin present an extraordinary study in epigraphic restraint. Carved without mechanical guidance, every glyph exhibits non-curvilinear facets governed by 45° and 60° stone cuts.

Unlike Mediterranean lapidary scripts that relied on compass arcs, the Eurasian carvers embraced the natural cleavage planes of granite. In doing so, they created a visual cadence of sharp chevron junctions and monumental weight.

5. Epigraphic Anatomy & Damga Geometry
Key architectural principles that unite Bengutas Display and Bengutas Sans
O C D G U

Faceted 45°/60° Chisel Planes

No compass curves. Circular letters are sculpted as octagonal, chiseled basalt rings, matching the physical constraint of bronze/iron chisels striking hard stone.

A K M W R

Orkhon Tamga Resonances

Acute angular vertexes and diagonal stems preserve the structural DNA of ancient Eurasian clan brands and runic letters while remaining fully legible Latin.

a b c d e

Automatic Petite Small-Caps

In Bengutas Display, lowercase input renders as harmoniously proportioned petite small-caps, echoing the monumental tradition where all stone writing is majuscule.

c e s r i l ç ş

Sans: Double-Chisel & Flat Baseline

Replaces blunt 90° box cutoffs with 25°–30° stone-chisel terminal cuts on open curves, lapidary apex cuts on stem heads, and authentic broken chevron hooks (ç, ş)—anchored by strictly flat baselines (y=800) for effortless continuous reading.

Web Integration (@font-face)

Include the WOFF2 files in your web project and use the following CSS rules: 

@font-face {
  font-family: 'Bengutas Display';
  src: url('BengutasDisplay-Regular.woff2') format('woff2');
  font-weight: 400;
  font-style: normal;
}
@font-face {
  font-family: 'Bengutas Display';
  src: url('BengutasDisplay-Bold.woff2') format('woff2');
  font-weight: 700;
  font-style: normal;
}
@font-face {
  font-family: 'Bengutas Sans';
  src: url('BengutasSans-Regular.woff2') format('woff2');
  font-weight: 400;
  font-style: normal;
}
@font-face {
  font-family: 'Bengutas Sans';
  src: url('BengutasSans-Bold.woff2') format('woff2');
  font-weight: 700;
  font-style: normal;
}

/* Recommended Usage */
h1, h2, .headline {
  font-family: 'Bengutas Display', serif;
  letter-spacing: 1.5px;
}
body, p {
  font-family: 'Bengutas Sans', sans-serif;
}
